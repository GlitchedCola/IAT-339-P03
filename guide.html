Main Navigation

.nav-main .nav-main-item, .nav-main-item:hover, .nav-main-time:focus

Sample code:

<nav class="nav-main qurova-text">
<a href="index.html" class="button-nav">Home</a>
<a href="previous-work.html" class="button-nav">Previous Work</a>
<a href="about.html" class="button-nav">About</a>
<a href="contact.html" class="button-nav">Contact</a>
</nav>
