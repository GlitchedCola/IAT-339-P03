Process Analysis 1

This is a short audio drama. This is a solo project for CMNS 226: Digital Storytelling for Public Engagement, where the objective was to create a narrative sequence that solely relies on sound. I used a mix of pre-recorded sounds and original audio (e.g. dialogue), which I then processed using different techniques.

One problem I encountered was that some of the sounds that I needed were not available in the sound libraries I was using. In order to resolve this, I had to create my own sounds. For some sounds, this was fairly easy (e.g. knocking on a table to create a door-knocking sound), while others required some audio processing to create the desired sound.

Another challenge was that some scenes involved a transition in settings (e.g. going from a bustling city to the inside of an office), which is not easy to do when you lack a visual component. I solved this by establishing clear soundscapes for each setting (e.g. traffic sounds for a cityscape, fax/printing sounds and faint voices for a busy office). I also used transition sounds (e.g. sliding doors opening and closing) and techniques like fade-in/fade-out to clearly convey that the protagonist is moving from one environment to another.

Through this project, I gained further experience using different processing techniques, and I learned how to tell narratives using only soundscapes and sound effects to support dialogue.

Process Analysis 2

This is a narrative soundscape. It was a solo project for CA149: Sound. The objective of this project was to create a story told through an environmental soundscape (i.e. no dialogue). I used a mix of sounds sourced from a sound library and original sounds, which I processed to create a layered audio environment.

The main challenge with this assignment was creating the layered environment, as I needed to make the listener feel like the sounds were coming from different directions and different distances. To do this, I placed sounds on different audio tracks based on their distance (e.g. background, foreground) and their positioning (e.g., on the listener’s left).

Another challenge was designing sounds to represent certain elements of the soundscape. The soundscape had a fantasy theme to it, so certain elements needed original sounds as there were no appropriate sounds available in the sound library (e.g there were no specific “fairy” noises). As such, I had to record new sounds/take existing sounds and modify them so that they were representative of their respective elements (e.g. modifying the sound of wind chimes to make them into a “fairy-like” sound).

This project taught me how to create soundscapes, which are useful for immersing your audience in an environment. This is also a valuable skill for film and video games, as even though you can visually show your audience an environment, in order to properly immerse them in an environment, you need to support it with a soundscape.
